# A→B Trips, Mission Codes & PRIM Call Guard — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a RER/Transilien tracked stop carry an optional arrival stop (only trains serving A then B are shown), display mission codes, and add a configurable PRIM call guard.

**Architecture:** Pure SIRI/guard logic goes in a new `src/pkjs/trips.js` (CommonJS, unit-tested under plain Node). `src/pkjs/index.js` wires it into the existing `refreshStop` → `departureUpdate` flow, firing two `stop-monitoring` requests (A and B) for trips. The config page gains an arrival-stop search, a return-trip button and guard settings. The watch only gains 4 short AppMessage keys and small layout changes — no new Skin/Style/screen/timer.

**Tech Stack:** Pebble Alloy (Moddable XS / Piu) on `emery`, pkjs (webpack 1 bundle — no `?.` / `??`), Node 24 `node:test` for unit tests, PRIM SIRI Lite `stop-monitoring`.

## Review Focus

1. Guard `maxCalls` = 1 with an A→B trip (2 calls per refresh) must not lock the user in a permanent pause — `normalizeCallGuard` raises any positive value below 2 to 2 (test in Task 3).
2. A train seen at both A and B but travelling B→A (both directions are mixed in a stop area) must be excluded — B's `Order` is lower (test in Task 2).
3. A config saved before this change (no `callGuard`, no `destStopRef`, legacy `destinations`) must keep working: guard defaults, "all trains" (tests in Task 3 + manual check in Task 4/6).
4. Phone clock moved backwards after a pause started (`pausedUntil` far in the future) must not pause forever — a pause longer than `pauseMinutes` from now is treated as expired (test in Task 3).
5. A malformed visit (missing `MonitoredCall` or journey ref) must be skipped, not crash the refresh into a bogus `network` error (test in Task 2).

```js
// Pure SIRI helpers for A->B trips and the PRIM call guard -- no Pebble,
// XMLHttpRequest or localStorage access, so test/*.test.js can run them
// under plain Node. Field shapes: docs/idfm-api-reference.md ("SNCF
// journey fields used for A->B trips").
// No `?.` / `??` here: the SDK's webpack 1 bundler predates ES2020.

/**
 * @param {object} journey - A SIRI MonitoredVehicleJourney.
 * @returns {string[]} Every identity key available for this train: the
 *   dated journey ref first, then the train number. Several keys so a
 *   train missing one of them on one side still matches on the other.
 */
function journeyKeys(journey) {
	const keys = [];
	const framed = journey.FramedVehicleJourneyRef;
	if (framed && framed.DatedVehicleJourneyRef) {
		keys.push("ref:" + framed.DatedVehicleJourneyRef);
	}
	const numbers = journey.TrainNumbers ? journey.TrainNumbers.TrainNumberRef : null;
	const number = (numbers || [])[0];
	if (number && number.value) keys.push("num:" + number.value);
	return keys;
}

/**
 * @param {object} call - A SIRI MonitoredCall.
 * @returns {number|null} Epoch ms of the best available time field, or
 *   null (same field order as callMinutesRemaining in index.js).
 */
function callTimeMs(call) {
	const field =
		call.ExpectedArrivalTime ||
		call.ExpectedDepartureTime ||
		call.AimedArrivalTime ||
		call.AimedDepartureTime;
	if (!field) return null;
	const ms = new Date(field).getTime();
	return Number.isNaN(ms) ? null : ms;
}

/**
 * @param {object} callA - The train's MonitoredCall at A.
 * @param {object} callB - The same train's MonitoredCall at B.
 * @returns {boolean} True when the train reaches B after A: by stop
 *   sequence (`Order`) when both sides have it, by time otherwise.
 */
function reachesBAfterA(callA, callB) {
	if (typeof callA.Order === "number" && typeof callB.Order === "number") {
		return callB.Order > callA.Order;
	}
	const timeA = callTimeMs(callA);
	const timeB = callTimeMs(callB);
	return timeA !== null && timeB !== null && timeB > timeA;
}

/**
 * @param {object} visit - A SIRI MonitoredStopVisit.
 * @returns {boolean} True when it has the fields the A->B join needs.
 */
function isUsableVisit(visit) {
	const journey = visit && visit.MonitoredVehicleJourney;
	return !!(journey && journey.MonitoredCall);
}

/**
 * @param {object[]} visitsA - MonitoredStopVisit list at the boarding stop.
 * @param {object[]} visitsB - MonitoredStopVisit list at the arrival stop
 *   (both directions mixed, as a stop area returns them).
 * @returns {object[]} The visits of `visitsA` whose train also calls at B
 *   afterwards, unchanged and in their original order.
 */
function filterVisitsServingStop(visitsA, visitsB) {
	const callsAtB = new Map();
	for (const visit of visitsB) {
		if (!isUsableVisit(visit)) continue;
		const journey = visit.MonitoredVehicleJourney;
		for (const key of journeyKeys(journey)) {
			callsAtB.set(key, journey.MonitoredCall);
		}
	}
	return visitsA.filter((visit) => {
		if (!isUsableVisit(visit)) return false;
		const journey = visit.MonitoredVehicleJourney;
		for (const key of journeyKeys(journey)) {
			const callB = callsAtB.get(key);
			if (callB) return reachesBAfterA(journey.MonitoredCall, callB);
		}
		return false;
	});
}

/**
 * @param {object} journey - A SIRI MonitoredVehicleJourney.
 * @returns {string} Mission code (e.g. "SORO"), "" if absent.
 */
function journeyMission(journey) {
	const note = (journey.JourneyNote || [])[0];
	return note && note.value ? note.value : "";
}

module.exports = {
	filterVisitsServingStop: filterVisitsServingStop,
	journeyMission: journeyMission,
};
```

- [ ] **Step 3: Implement the guard in `src/pkjs/trips.js`**

Add before `module.exports`:

```js
const DEFAULT_CALL_GUARD = { maxCalls: 40, windowMinutes: 10, pauseMinutes: 15 };
const MINUTE_MS = 60000;

/**
 * @param {*} value
 * @param {number} min
 * @param {number} fallback
 * @returns {number} `value` as an integer >= min, or `fallback`.
 */
function intAtLeast(value, min, fallback) {
	const n = Math.floor(Number(value));
	return Number.isFinite(n) && n >= min ? n : fallback;
}

/**
 * @param {object} [settings] - Config page's `callGuard` (may be missing
 *   in configs saved before the guard existed).
 * @returns {{maxCalls: number, windowMinutes: number, pauseMinutes: number}}
 *   Sanitized settings. A positive maxCalls below 2 becomes 2: an A->B
 *   refresh costs 2 calls at once and would otherwise never pass.
 */
function normalizeCallGuard(settings) {
	const s = settings || {};
	let maxCalls = intAtLeast(s.maxCalls, 0, DEFAULT_CALL_GUARD.maxCalls);
	if (maxCalls === 1) maxCalls = 2;
	return {
		maxCalls: maxCalls,
		windowMinutes: intAtLeast(s.windowMinutes, 1, DEFAULT_CALL_GUARD.windowMinutes),
		pauseMinutes: intAtLeast(s.pauseMinutes, 1, DEFAULT_CALL_GUARD.pauseMinutes),
	};
}

/**
 * Decides whether a refresh may spend `count` PRIM calls now.
 * @param {{calls: number[], pausedUntil: number}|null} state - Persisted
 *   guard state (null on first use).
 * @param {object} [settings] - Raw `callGuard` settings.
 * @param {number} now - Epoch ms.
 * @param {number} count - Calls this refresh needs (1, or 2 for A->B).
 * @returns {{allowed: boolean, minutesLeft: number,
 *   state: {calls: number[], pausedUntil: number}}} `state` is the new
 *   state to persist; `minutesLeft` (rounded up) is only meaningful when
 *   refused.
 */
function decideCallGuard(state, settings, now, count) {
	const s = normalizeCallGuard(settings);
	if (s.maxCalls === 0) {
		return { allowed: true, minutesLeft: 0, state: { calls: [], pausedUntil: 0 } };
	}
	let pausedUntil = (state && state.pausedUntil) || 0;
	// A pause can't legitimately end later than pauseMinutes from now --
	// if it does, the phone clock moved backwards: drop it rather than
	// pausing for hours.
	if (pausedUntil - now > s.pauseMinutes * MINUTE_MS) pausedUntil = 0;
	if (pausedUntil > now) {
		return {
			allowed: false,
			minutesLeft: Math.ceil((pausedUntil - now) / MINUTE_MS),
			state: { calls: [], pausedUntil: pausedUntil },
		};
	}
	const windowStart = now - s.windowMinutes * MINUTE_MS;
	const calls = ((state && state.calls) || []).filter((t) => t > windowStart);
	if (calls.length + count > s.maxCalls) {
		return {
			allowed: false,
			minutesLeft: s.pauseMinutes,
			state: { calls: [], pausedUntil: now + s.pauseMinutes * MINUTE_MS },
		};
	}
	for (let i = 0; i < count; i++) calls.push(now);
	return { allowed: true, minutesLeft: 0, state: { calls: calls, pausedUntil: 0 } };
}
```

const jsPath = path.join(root, "src", "pkjs", "index.js");

/**
 * Fetches one stop's visits for a line and calls `done(state, visits)`:
 * state "ok" with the MonitoredStopVisit list, or a failure state
 * ("quotaExceeded", "invalidKey", "invalidStop", "network") with no visits.
 * @param {string} apiKey
 * @param {string} stopRef

 * @param {function(string, object[]=): void} done

function fetchStopVisits(apiKey, stopRef, lineRef, done) {
	const url =
		STOP_MONITORING_URL +
		"?MonitoringRef=" +
		encodeURIComponent(stopRef) +
		"&LineRef=" +
		encodeURIComponent(lineRef);
	const xhr = new XMLHttpRequest();
	xhr.open("GET", url, true);
	xhr.setRequestHeader("apiKey", apiKey);
	xhr.onload = () => {
		if (xhr.status === 429) return done("quotaExceeded");
		if (xhr.status === 401 || xhr.status === 403) return done("invalidKey");
		if (xhr.status === 400 || xhr.status === 404) {
			console.log(`stop-monitoring ${xhr.status} for ${stopRef}`);
			return done("invalidStop");
		}
		if (xhr.status < 200 || xhr.status >= 300) return done("network");
		let visits;
		try {

		} catch (error) {
			console.log("stop-monitoring parse error: " + error);
			return done("network");
		}
		done("ok", visits);
	};
	xhr.onerror = () => done("network");
	lastQuotaRemaining = recordPrimRequestAndGetQuotaRemaining();
	xhr.send();

/**

function worstState(states) {
	for (const state of FAILURE_PRIORITY) {

/**

 * reply: drops visits without a usable time (the "undefined min" bug, see
 * callMinutesRemaining), sorts running trains first then at-stop first
 * then by minutes, and attaches the first two departures' mission codes.
 * @param {object[]} visits - MonitoredStopVisit list.
 * @param {string} lineName
 * @param {function(string, object=): void} reply
 */
function replyWithDepartures(visits, lineName, reply) {
	const departures = visits
		.map((visit) => visit.MonitoredVehicleJourney)
		.filter((journey) => journey && journey.MonitoredCall)
		.map((journey) => {
			const call = journey.MonitoredCall;
			const atStop = call.VehicleAtStop === true;
			const minutes = callMinutesRemaining(call);
			return {
				journey: journey,
				atStop: atStop,
				cancelled: call.DepartureStatus === "cancelled",
				// ExpectedArrivalTime can be slightly in the past before
				// VehicleAtStop flips (real-hardware evidence) -- floor at 0.

				rank: atStop ? -1 : minutes,

		.filter((d) => d.atStop || d.minutes !== null)
		// Running trains first: a cancelled one is only shown when nothing
		// else is announced, so it can't hide the real next departure.
		.sort(
			(a, b) => Number(a.cancelled) - Number(b.cancelled) || a.rank - b.rank
		);

	if (departures.length === 0) {
		reply("noRealtimeData");
		return;
	}

	const first = departures[0];
	const extra = {
		lineName: lineName,
		destination: journeyDestinationName(first.journey),
		// -1 when atStop is a sentinel the watch ignores in favor of atStop.
		minutes: first.atStop ? -1 : first.minutes,
		atStop: first.atStop,
		cancelled: first.cancelled,
	};
	const mission = journeyMission(first.journey);
	if (mission) extra.mission = mission;
	// The watch prints minutes2 as-is (no at-stop flag for it), hence 0
	// rather than -1. Omitted when there's no running following departure.
	if (departures.length > 1 && !departures[1].cancelled) {
		const second = departures[1];
		extra.minutes2 = second.atStop ? 0 : second.minutes;
		const mission2 = journeyMission(second.journey);
		if (mission2) extra.mission2 = mission2;
	}
	reply("ok", extra);
}

/**
 * Handles a watch-sent `refreshStop`: one stop-monitoring request on A, or
 * two in parallel (A and B) for an A->B trip, kept to trains serving A then
 * B (filterVisitsServingStop). Replies with one `departureUpdate`.
 * @param {{stopRef: string, lineRef: string, lineName: string,
 *   destStopRef?: string}} request
 */
function handleRefreshStop(request) {
	const destStopRef = request.destStopRef || "";
	const reply = (state, extra) =>
		sendDepartureUpdate(
			request.stopRef,
			request.lineRef,
			destStopRef,
			state,
			extra
		);

	if (DEV_FAKE_DEPARTURES) {
		const minutes = 1 + Math.floor(Math.random() * 15);
		reply("ok", {
			lineName: request.lineName,
			destination: "Terminus (donnée factice)",
			minutes: minutes,
			minutes2: minutes + 3 + Math.floor(Math.random() * 10),
			atStop: false,
			cancelled: false,
			mission: "FAKE",
			mission2: "TEST",
		});
		return;
	}

	const refs = destStopRef ? [request.stopRef, destStopRef] : [request.stopRef];
	// Configs saved before the monomodalStopPlace fix (see idfmIdToStif in
	// CONFIG_HTML) carry a ref with no numeric id -- PRIM can only reject it.
	if (refs.some((ref) => /:monomodalStopPlace:$/.test(ref))) {
		reply("invalidStop");
		return;
	}

	const config = storedConfig();
	const guard = checkCallGuard(config, refs.length);
	if (!guard.allowed) {
		reply("rateLimited", { minutes: guard.minutesLeft });
		return;
	}

	const apiKey = config ? config.apiKey : "";
	const results = [];
	let pending = refs.length;
	refs.forEach((ref, i) => {
		fetchStopVisits(apiKey, ref, request.lineRef, (state, visits) => {
			results[i] = { state: state, visits: visits };
			pending -= 1;
			if (pending > 0) return;
			const failure = worstState(results.map((r) => r.state));
			if (failure !== "ok") {
				reply(failure);
				return;
			}
			try {
				const kept = destStopRef
					? filterVisitsServingStop(results[0].visits, results[1].visits)
					: results[0].visits;
				replyWithDepartures(kept, request.lineName, reply);
			} catch (error) {
				console.log("departureUpdate build error: " + error);
				reply("network");
			}
		});
	});
}

/**
 * Sends a `departureUpdate` AppMessage for one tracked trip. stopRef,
 * lineRef and destStopRef are echoed back: together they are the watch's
 * key (a stop area is shared by several lines, and one stop+line can be
 * tracked towards several arrivals).
 * @param {string} stopRef
 * @param {string} lineRef
 * @param {string} destStopRef - "" when the trip has no arrival (omitted).
 * @param {"ok"|"network"|"noRealtimeData"|"quotaExceeded"|"invalidKey"|"invalidStop"|"rateLimited"} state
 * @param {object} [extra] - lineName, destination, minutes, minutes2,
 *   atStop, cancelled, mission, mission2 for "ok"; minutes for "rateLimited".
 */
function sendDepartureUpdate(stopRef, lineRef, destStopRef, state, extra) {
	const payload = Object.assign(
		{
			itemType: "departureUpdate",
			stopRef: stopRef,
			lineRef: lineRef,
			state: state,
		},
		extra || {}
	);
	if (destStopRef) payload.destStopRef = destStopRef;
	// Attached to every reply regardless of state so the watch's settings
	// screen always reflects the latest known count.
	if (lastQuotaRemaining !== null) payload.quotaRemaining = lastQuotaRemaining;
	Pebble.sendAppMessage(payload);
}
